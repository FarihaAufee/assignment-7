# 🛒 বাজার দর | BazarDor

### Know Today's Market Prices at a Glance

**বাজার দর (BazarDor)** is a web application that helps users explore daily market prices of essential products in Bangladesh. Users can check current prices, compare price changes, browse products by category, and stay informed about rising and falling market prices through a simple and responsive interface.

## ✨ Key Features

- **📈 Rising Prices:** Discover products whose prices are increasing.
- **📉 Falling Prices:** Find products whose prices are decreasing.
- **🔍 Product Details:** View product prices, previous prices, price changes, and market information.
- **🗂️ Category-Based Browsing:** Explore products by categories such as vegetables, fish, fruits, oil, spices, and lentils.
- **📱 Responsive Design:** Enjoy a user-friendly experience on desktop, tablet, and mobile devices.

## 🛠️ Technologies Used

- **Next.js** — React framework for building web applications
- **React** — Component-based user interface
- **TypeScript** — Type-safe JavaScript development
- **Tailwind CSS** — Responsive styling and UI design
- **REST API** — Dynamic product and category data fetching
- **React Icons** — Icons for an enhanced user interface
- **Git & GitHub** — Version control and project hosting

## 🚀 Getting Started

### Prerequisites

Make sure you have the following installed:

- Node.js
- npm
- Git

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/FarihaAufee/assignment-7.git
   ```

2. Navigate to the project directory:

   ```bash
   cd assignment-7
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open [http://localhost:3000](http://localhost:3000) in your browser.

## 📂 Project Purpose

BazarDor aims to make daily market price information more accessible and help people make informed purchasing decisions.
